PAra executar esse projeto, siga as instruções a seguir:

1. Criar um ambiente virtual apython
$ python -m venv venv

no linux:
$ python3 -m venv venv

2. Ativar o ambiente virtual
$ venv\Scripts\activate

no linux:
$ source bin\activate

3. Instale os requierments:
$ pip install -r requierments.txt

4. Ao final, execute o projeto:
$ streamlit run main.py
